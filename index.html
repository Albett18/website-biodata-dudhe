My Journey in SA-MP

Perjalanan saya di dunia GTA San Andreas Multiplayer (SA-MP) dimulai sejak masa pandemi COVID-19. Saat itu, saya mulai mengenal dunia roleplay melalui server pertama saya, Green City Roleplay. Di sanalah saya mendapatkan pengalaman pertama sekaligus mengenal seseorang bernama Ghogi, orang pertama yang membimbing dan mengajarkan saya cara bermain SA-MP hingga mulai memahami dunia roleplay. Seiring berjalannya waktu, saya sempat berhenti bermain untuk beberapa saat. Namun, ketertarikan terhadap dunia SA-MP membawa saya kembali. Saya mulai menjelajahi berbagai komunitas dan mendapatkan banyak pengalaman baru di beberapa server besar, seperti TEN Roleplay dan Nexotis. Kini, perjalanan saya tidak lagi sebatas menjadi seorang pemain. Bersama Arya, saya sedang mengembangkan sebuah server bernama Evergreen Roleplay, sebuah proyek yang menjadi langkah baru bagi saya untuk belajar, berkarya, dan membangun komunitas sendiri. Bagi saya, SA-MP bukan sekadar permainan, melainkan tempat di mana saya menemukan teman, pengalaman, dan berbagai cerita yang menjadi bagian dari perjalanan saya hingga saat ini.
